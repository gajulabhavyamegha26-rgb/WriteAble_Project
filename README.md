# WriteAble

An accessible writing support website. It helps anyone write with confidence, no matter how they read, type, or see.

First-year CSE mini project | Team of 4

## Features

- Grammar and spelling check with one-click fixes (LanguageTool API)
- Live word and sentence counter
- Voice input: dictate instead of typing (Web Speech API)
- Text size slider, light, dark and high-contrast themes
- Dyslexia-friendly font and Read Aloud
- Settings remembered on every page
- Writing tips, grammar guide and downloadable templates
- Keyboard and screen-reader friendly

## Tech stack

HTML, CSS, JavaScript. No backend. LanguageTool API, Web Speech API, localStorage, Git and GitHub.
